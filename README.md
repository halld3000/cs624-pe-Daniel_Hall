Input 
React Native application consists of text values and styling instructions. Values are provided via JSX code used in Reacts Text components, the SyleSheet is used to define the values for the background color, font size, and alignment.
Process
Input is processed through the App function; this is used to define the user interface. The View components are housed in a container. Styling is applied using react style properties, this provides the layout of all the elements. Flex property is used to fill space, “justifyContent”, and “alignItems” properties are used to center the text group in the center of the screen.
Output 
With the use of Expo I was able to run and test the application on my mobile device. I was able to successfully display the required output of a yellow background and the three lines of text centered on my device.
