Input
CoreComponents mobile app displays course required for the MSCS program. Input is provided buy the "TextInput" component, this allows users to enter the course they want from the pre-defined information stored in the JavaScript arrays.

Process
Using .map() method it loops through each array and generates individual Text components. The StyleSheet defines the application's appearance, including font sizes, spacing, and yellow section headings. The ScrollView component allows users to navigate through the course list vertically.

Output
Output displays eight courses and two depth of study courses and one capstone. Users can view course information by entering it into the text field.
